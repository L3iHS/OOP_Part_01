# Лабораторная 1 — основы C++

Задание: написать консольную программу для работы с динамическим массивом целых чисел. **Вариант 4.**

## Что требуется

Программа должна позволять создать и вывести массив, вставить или удалить элемент и изменить размер массива. Для варианта 4 также нужно:

- отсортировать массив по возрастанию гномьей сортировкой;
- искать значение бинарным поиском в отсортированном массиве;
- удалить все вхождения заданного числа, сдвигая оставшиеся элементы влево. Операция должна обновить размер по ссылке и вернуть число удалённых элементов.

Например, удаление `2` из `{2, 5, 2, 8, 2, 1}` должно оставить `{5, 8, 1}`, установить размер `3` и вернуть `3`.

## Условия задания

- C++20 и система сборки CMake.
- Динамический массив создаётся и освобождается вручную через `new[]` и `delete[]`.
- Нельзя использовать `std::vector`, `std::array`, `std::string` и умные указатели.
- Логика работы с массивом оформляется отдельными функциями; ввод и вывод остаются в программе меню.
- Для проекта требуется не менее 10 тестов Google Test.

## Файлы

- `main.cpp` — точка входа и меню программы.
- `src/array_ops.hpp` и `src/array_ops.cpp` — объявления и реализации операций с массивом.
- `tests/test_funcs.cpp` — тесты базовых операций с массивом.
- `tests/test_variant.cpp` — тесты алгоритмов варианта 4.
- `CMakeLists.txt` — настройки сборки программы, библиотеки и тестов.

## Сборка и запуск

Требуются компилятор с поддержкой C++20 и CMake 3.16 или новее. Google Test 1.17.0 загружается автоматически при первой настройке сборки, для этого нужен интернет.

Команды выполняются из каталога лабораторной:

```sh
cmake -S . -B build
cmake --build build
./build/lab1
```

## Тесты

```sh
ctest --test-dir build --output-on-failure
```

Для CMake 3.16–3.19 запускать CTest нужно из каталога сборки:

```sh
cd build
ctest --output-on-failure
```

Для сборки только программы, без загрузки Google Test:

```sh
cmake -S . -B build-app -DBUILD_TESTING=OFF
cmake --build build-app
./build-app/lab1
```
