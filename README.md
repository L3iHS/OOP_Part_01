# Объектно-ориентированное программирование

Лабораторные работы по первой части курса «Объектно-ориентированное программирование» в МАИ.

## Лабораторные работы

- [Лабораторная работа 1 — основы C++](lab_1_basics/README.md): динамический массив, вариант 4.
- [Лабораторная работа 2 — класс String](lab_02_string/README.md): ручное управление памятью, RAII и правило пяти, вариант 2.
- [Лабораторная работа 3 — класс TemperatureSet](lab_03_temperature/README.md): множество температур, вариант 13.

Каждая лабораторная работа находится в отдельном каталоге со своим README.

## Сборка

Команды выполняются из каталога выбранной лабораторной работы. Например, для первой:

```sh
cd lab_1_basics
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```
