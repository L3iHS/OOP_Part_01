# Лабораторная работа 3 — множество температур

Вариант 13. `TemperatureSet` хранит уникальные температуры в динамическом массиве.

## Требования

- C++20, CMake 3.20+ и тесты Google Test.
- Память выделяется через `new[]` и освобождается через `delete[]`. При первом добавлении ёмкость равна 1, при заполнении массива она удваивается.
- Правило пяти, глубокое копирование, присваивание через copy-and-swap и перемещение за O(1) с обнулением источника.
- Без шаблонов, контейнеров STL, `std::string` и умных указателей.

## Вариант 13

`Temperature` принимает число в градусах Цельсия (`C`), градусах Фаренгейта (`F`) или кельвинах (`K`). Конструктор переводит значение в градусы Цельсия и округляет до миллионной доли градуса, чтобы погрешность пересчёта не разделяла одинаковые температуры. Например, `20 C`, `68 F` и `293.15 K` обозначают один элемент множества. `add` отклоняет бесконечность и `NaN`.

Массив сохраняет порядок добавления. Поиск выполняется линейно, а удаление сдвигает следующие элементы влево. Вывод использует градусы Цельсия, например `{ 20 °C, 0 °C }`.

## Интерфейс и поведение

| Метод или оператор | Назначение |
|---|---|
| `add`, `remove` | Добавление или удаление элемента с возвратом признака изменения |
| `contains`, `operator()` | Проверка принадлежности |
| `size`, `empty` | Количество элементов и проверка на пустоту |
| `+=`, `-=` | Добавление или удаление одного элемента с возвратом ссылки на множество |
| `A \| B` | Объединение. Сначала идут элементы `A`, затем новые элементы `B` |
| `A & B` | Пересечение в порядке хранения `A` |
| `A - B` | Элементы `A`, отсутствующие в `B`, в порядке хранения `A` |
| `==`, `!=` | Сравнение по составу независимо от порядка добавления |
| `<<` | Вывод множества в фигурных скобках |

## Файлы

- `src/temperature.hpp` и `src/temperature.cpp` — температура, пересчёт единиц, сравнение и вывод.
- `src/temperature_set.hpp` и `src/temperature_set.cpp` — динамический массив и операции над множеством.
- `src/main.cpp` — консольное меню для двух множеств.
- `tests/test_temperature.cpp` — преобразование единиц, сравнение и вывод температуры.
- `tests/test_lifecycle.cpp` — копирование, перемещение и присваивание.
- `tests/test_operations.cpp` — операции над множествами, порядок вывода и проверка на 1000 элементах.
- `CMakeLists.txt` — настройки сборки и тестов.

## Сборка и запуск

Команды выполняются из каталога лабораторной работы.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
./build/lab_03
ctest --test-dir build --output-on-failure
```

Google Test 1.17.0 загружается при первой настройке сборки. Для сборки только программы используйте `-DBUILD_TESTING=OFF`.

В меню можно добавлять, удалять и искать температуры в множествах `A` и `B`. Для ввода используйте число с единицей, например `68 F`. Пункт 6 выводит объединение, пересечение и разность.

## Проверка памяти

Для GCC и Clang доступна сборка с AddressSanitizer и UBSan.

```sh
cmake -S . -B build-sanitize -DCMAKE_BUILD_TYPE=Debug -DENABLE_SANITIZERS=ON
cmake --build build-sanitize
ctest --test-dir build-sanitize --output-on-failure
```

В macOS утечки можно проверить командой `leaks --atExit -- ./build/lab_03_tests`.
